┌──────────────────────────────────────────────────────────────────────────────┐
│ HOW IT WORKS (SIMPLIFIED)                                                    │
└──────────────────────────────────────────────────────────────────────────────┘

Step 1: UPLOAD
   User uploads photos/videos via web interface
   ↓
Step 2: FACE DETECTION
   System detects all faces using dlib
   Each face → 128-dimensional vector (embedding)
   ↓
Step 3: CLUSTERING
   DBSCAN automatically groups similar faces
   No need to specify number of people!
   ↓
Step 4: ORGANIZATION
   Creates folders: Person_1, Person_2, ..., Unknown
   Copies photos to appropriate folders
   Group photos → copied to multiple folders
   ↓
Step 5: DOWNLOAD
   User downloads organized ZIP file

┌──────────────────────────────────────────────────────────────────────────────┐
│ KEY ALGORITHMS EXPLAINED                                                     │
└──────────────────────────────────────────────────────────────────────────────┘

1. FACE DETECTION (dlib HOG)
   • Histogram of Oriented Gradients
   • Detects face-like patterns
   • Fast on CPU (~0.5s per image)

2. FACE EMBEDDINGS (ResNet)
   • Pre-trained deep learning model
   • Converts face → 128-d vector
   • Similar faces → similar vectors

3. DBSCAN CLUSTERING
   • Density-Based Spatial Clustering
   • Parameters: eps (distance), min_samples (minimum cluster size)
   • Automatically finds number of clusters
   • Handles outliers (Unknown folder)

4. EUCLIDEAN DISTANCE
   • Measures similarity between embeddings
   • distance < 0.6 → likely same person
   • Used by DBSCAN to group faces

┌──────────────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING COMMON ISSUES                                                │
└──────────────────────────────────────────────────────────────────────────────┘

❌ Problem: dlib won't install
✅ Solution:
   • Install Visual C++ Build Tools
   • Or use: pip install dlib-binary
   • Or use conda: conda install -c conda-forge dlib

❌ Problem: No faces detected
✅ Solution:
   • Use clear, well-lit photos
   • Ensure faces are visible (not too small)
   • Try different images

❌ Problem: Too many groups created
✅ Solution:
   • Increase eps parameter (e.g., 0.6)
   • Increase min_samples to 3

❌ Problem: Different people grouped together
✅ Solution:
   • Decrease eps parameter (e.g., 0.4)
   • Use higher quality images
